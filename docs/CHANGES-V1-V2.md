# V1 → V2 变化

| 项目 | V1 | V2 |
|---|---|---|
| 工具传输 | 请求内普通Java工具 | 官方MCP0.14.1客户端→Streamable HTTP→独立JVM服务 |
| 身份 | 后端直接传owner | Session捕获owner，短期签名audience/scope/Skill/请求绑定；两端验证 |
| Skills | 无 | 三份Schema校验配置；工具、步骤、调用和结果约束参与执行 |
| Agent | 单一工具决策流程 | 无工具协调器、独立知识和订单专业上下文；最多2次委派 |
| 总预算 | 3轮/8工具、2检索 | 跨进程数据库原子预算，包含最多12次所有模型调用和240秒 |
| MCP故障 | 不适用 | 明确失败、保留最近错误和真实发现结果，无本地回退 |
| 方案 | 确认及丢弃，TTL靠重绘 | 每秒过期更新、旧版本标记、持久化执行回执 |
| 运行记录 | 平铺JSONB展示 | 父子Agent、Skill版本、两端MCP、预算、解析JSONB、筛选分页 |
| 对话历史 | 时间+短ID | 时间+首条问题标题+消息时间+链路入口 |
| 环境 | 8081/15432/18082 | 独立8082/15433/18083/18084；独立Compose/库/卷/PID/日志 |
| 验证 | 历史31项后端；全量99/100后定向29/29 | 以V2验证报告中的实际构建、数量和失败记录为准 |

保留Java21、Boot3.3.3、Vaadin/Hilla24.4.11、LangChain4j1.24.0普通SDK、DeepSeek thinking关闭、中文BGE512维、pgvector、Flyway、BCrypt、Session/CSRF、隔离、统一算费、方案确认/丢弃并发、事务及真实SQL复核、实际Token记录。业务规则版本仍为demo-v1.0，不能因为产品升级而改写历史条款。V0/V1用户数据没有复制到V2或重置。
